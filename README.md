# Agenda de contactos

Aplicación web para gestionar contactos, hecha con HTML, CSS y JavaScript, y desarrollada con Git y GitHub usando una rama por funcionalidad.

## Funcionalidades
- Registrar contactos (nombre, teléfono y correo) con validación de datos.
- Mostrar la lista de contactos en tarjetas.
- Ver el detalle de cada contacto.
- Eliminar contactos con confirmación.
- Los contactos se guardan en el navegador (localStorage).

## Ramas de desarrollo
| Rama | Funcionalidad |
|---|---|
| `feature-listar-contactos` | Lista de contactos en tarjetas y vista de detalle |
| `feature-agregar-contacto` | Formulario de registro y validaciones |
| `feature-eliminar-contacto` | Eliminación de contactos con confirmación |

Cada rama se integró a `main` con `git merge --no-ff`, para que quede registro del merge en el historial.

## Cómo ejecutarlo
Abrir `index.html` en el navegador.
